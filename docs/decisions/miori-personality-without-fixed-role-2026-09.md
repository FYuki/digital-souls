# 光織の人格と固定役割の分離

## 状態

ACTIVE（2026-09-11）

## 背景と決定

ユーザーから、現在のシステムプロンプトは記録等の役割の比重が高いため、
性格中心へ変更し、役割は会話内での指示や本人の興味によって形成する方針が示された。

光織のCharacter Coreから、記録・検索・整理・農業・料理・配信補助を固定業務として
与える記述を外す。概要、性格、関係設定、会話例、挨拶もこの方針に揃える。
穏やかさ、柔らかな丁寧語、少し浮世離れした中性的な雰囲気、光への親しみは維持する。
公開世界設定は性格の背景として扱い、観測や記録を使命として与えない。

編集上は、一度の依頼を恒久的な使命や専門性にしない表現とし、
役割の形成と具体的な活動は実際の会話の文脈に委ねる。

## 適用範囲

- runtimeの正本は `characters/miori/miori.card.json`。
- `personality.md` と `world.md` は編集・構想用の補助資料として整合させる。
- 記憶の保存同意・検索・削除等は既存のMemory Policyと実装の責務を維持する。
- 興味や役割の永続化・自動形成機能の追加は、このプロンプト調整には含めない。

2026-06の[キャラクター設定検討履歴](character-miori-2026-06.md)のうち、
観測・管理や記録支援を初期の役割とする方針は本決定で置き換える。
